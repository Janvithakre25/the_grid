# Smart Grid Recommendation Engine & Severity Methodology Report

## Executive Summary
This report describes the rule-based operational recommendation engine that translates AI energy demand predictions, historical load percentiles, ambient temperature, and holiday/calendar metadata into actionable decision support for grid operators and utility managers.

**STRICT CONTROL POLICY:** The system provides decision-support recommendations only and does **NOT** execute direct hardware control on grid switches or equipment.

---

## 1. Severity Classification Methodology

The severity level of a state's forecasted load is determined using historical empirical demand percentiles computed per state:

- **HIGH Severity:** Forecasted Load $\ge P_{90}$ (90th percentile of state historical demand).
- **LOW Severity:** Forecasted Load $\le P_{10}$ (10th percentile of state historical demand).
- **NORMAL Severity:** Forecasted Load lies between $P_{10}$ and $P_{90}$.

---

## 2. Recommendation Logic & Action Mapping Matrix

| Severity Level | Ambient Temperature Condition | Recommended Operational Action | Operational Objective |
| :--- | :--- | :--- | :--- |
| **HIGH** | $\text{Temp} \ge 35^\circ\text{C}$ | **CRITICAL PEAK LOAD WARNING:** High heat index anticipated. Initiate pre-cooling via HVAC scheduling & trigger industrial demand-response load shaving. | Peak-load reduction & preventing thermal overload |
| **HIGH** | $\text{Temp} < 35^\circ\text{C}$ | **PEAK DEMAND ALERT:** Trigger peak load shifting; suggest shifting flexible agricultural & commercial pumping loads to off-peak hours. | Load shifting & grid congestion alleviation |
| **NORMAL** | Any Temperature | **NORMAL OPERATING RANGE:** Standard grid balance. Maintain automatic generation control (AGC) & spinning reserve margins. | Standard baseline stability |
| **LOW** | Any Temperature | **OFF-PEAK WINDOW:** Excellent window for scheduled thermal generator maintenance and maximum absorption of renewable power. | Asset maintenance & renewable absorption |
